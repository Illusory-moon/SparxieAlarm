# 火警 SparxieAlarm

> 名字是**角色自己取的**：「火警」——火花 + 报警，还带一层消防员的意思。

一个很小的 AstrBot 插件：**当它发现自己身上某个功能出毛病时，会用自己的语气去找「运营」报修。**

## 它做什么

只做三件事：**登记 / 递话头 / 销账**。

1. **登记**：这一轮跑完时扫一遍 agent 的工具结果（**只看 `role == "tool"`**），命中约定失败话术就记一笔。
2. **递话头**：它下次开口前（`on_llm_request`，临时内容、不进历史）给一句中性提示：
   「（插一句：<功能> 在 <时间> 出过一次毛病，现在还没好。你要是想，可以去找「运营」说一声 —— 用你自己的说法就行。）」
3. **销账**：它要是真去 @ 了人，就把这笔销掉；24 小时没动静允许再催一次，最多两次。

**它不会宣布「修好了」** —— 那是运营在群里亲口说的事。

## 设计上的三条硬约束

- **判据只对工具结果生效**：绝不扫角色正文，否则它说一句「失败了」就会被当成故障（模型会报假 bug）。
- **提示里不许出现任何人名 / 号码**：找谁，是它自己的事。
- **先紧后松**：默认只认内置的约定失败话术；框架通用失败词（`error:` 等）要显式打开配置才认。

## 安装

放到 AstrBot 的 `data/plugins/` 下，重启后在插件配置里开启 `enabled`，并把你希望生效的 bot ID 填进 `enabled_self_ids`（留空 = 谁都不启用）。

## 数据

状态只有一份 `alarm_state.json`，在插件数据目录里：只记「哪个工具、什么失败话术、什么时候」，
**不记对话内容** ✓。
